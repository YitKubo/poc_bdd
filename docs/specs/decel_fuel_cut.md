# 減速時燃料カット

テスト: [decel_fuel_cut.feature](../../tests/features/decel_fuel_cut.feature)

## 目的

減速中の無駄な燃料噴射を止めて燃費を良くする。

## 振る舞い

- スロットルが全閉で、エンジン回転数が開始回転数を**超えた**ら燃料をカットする
- カット中は、回転数が復帰回転数**以下**になるか、スロットルが全閉でなくなったら噴射を再開する
- 開始回転数と復帰回転数の間ではカットの状態を保つ（ヒステリシス）

## パラメータ

| 名前 | 値 | 意味 |
|---|---|---|
| DECEL_THROTTLE_CLOSED_PCT | 2 % | この開度以下を全閉とみなす |
| DECEL_CUT_ABOVE_RPM | 1500 rpm | 超えたらカット |
| DECEL_RECOVER_RPM | 1100 rpm | 以下で復帰 |

## 状態の動き

```plantuml
@startuml
[*] --> 噴射 : 
噴射 --> カット : 全閉 かつ 回転数 > 1500
カット --> 噴射 : 回転数 <= 1100 または 全閉でない
@enduml
```
