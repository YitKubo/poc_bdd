# レブリミッタ

テスト: [rev_limiter.feature](../../tests/features/rev_limiter.feature)

## 目的

エンジンの回りすぎを防ぎ、壊れないようにする。

## 振る舞い

- エンジン回転数が上限回転数に**達したら**（以上）燃料をカットする
- カット中は、回転数が復帰回転数**以下**になったら噴射を再開する
- 上限回転数と復帰回転数の間ではカットの状態を保つ（ヒステリシス）
- スロットル開度には関係なく働く

## パラメータ

| 名前 | 値 | 意味 |
|---|---|---|
| REV_LIMIT_RPM | 6500 rpm | 以上でカット |
| REV_RECOVER_RPM | 6300 rpm | 以下で復帰 |

## 補足

燃料カットの出力は [decel_fuel_cut.md](decel_fuel_cut.md) と共通で、どちらかの条件が成り立てばカットする。
